## 🌊 Welcome to Akuyrium!

**Akuyrium** is an independent software project focused on creating a unique digital space for creativity, customization and exploration.

Designed with its own visual identity, Akuyrium aims to bring together useful tools and a delightful user experience in one place.

We're currently working on the project and preparing its future releases.

## 💎 Design philosophy

Akuyrium's visual identity takes inspiration from the **Frutiger Aero** aesthetic.

Some of its visual inspirations include:

- 💧 Aqua and turquoise color palettes.
- 🫧 Glass-like surfaces and transparency.
- 🌤️ Soft gradients and luminous details.
- 🐠 Aquatic and nature-inspired elements.
- ✨ Rounded interfaces and playful interactions.

A little nostalgia, a little futuristic atmosphere, and a lot of personality.
